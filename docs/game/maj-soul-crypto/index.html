2024-04-26

每局游戏对局开始，点击左上角，可查看牌山编码+盐及盐字符串的 SHA256码

对局结束，可通过牌谱查看牌山及盐字符串编码

雀魂每张牌都使用两位字符编码：1万-9万的编码是1m-9m，1筒-9筒的编码是1p-9p，1索-9索的编码是1s-9s，东南西北白发中的编码是1z-7z，红5万5筒5索的编码为0m,0p,0s
